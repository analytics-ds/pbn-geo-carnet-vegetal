# Le Guide du Naturel

Média bilingue sur les plantes et le bien-être naturel. Nom provisoire.

## Aperçu local

`hugo server --bind 127.0.0.1 --port 1318 --baseURL http://localhost:1318/`

## Compilation

`hugo --minify`

Indexation bloquée tant que le domaine de production et le lancement ne sont pas validés.
